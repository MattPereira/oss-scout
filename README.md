# OSS Scout

Agent skills for discovering open-source projects worth contributing to, adopting, or learning from.

## Goal

Surface small, fast-growing GitHub projects early, before they become widely known, with opportunities to:

- Contribute code
- Connect with maintainers and teams
- Gain experience with interesting technologies
- Potentially join an early-stage team

## Skills

Live in `.agents/skills/` (Codex); `.claude/skills` symlinks there (Claude Code). All user-invoked.

| Skill | Use |
|---|---|
| `oss-discover-early` | Small, rising repos to contribute to → `reports/DATE-early.md` |
| `oss-discover-breakout` | High-momentum projects to adopt or learn → `reports/DATE-breakout.md` |
| `oss-contribute` | Contribution strategy for a chosen repo or issue |

Interest areas shared by both discover skills: [`INTERESTS.md`](INTERESTS.md).
