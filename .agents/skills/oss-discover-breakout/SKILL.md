Spot projects gaining big momentum, any size, and decide whether each deserves adoption or study.

## Sources

- [GitHub Trending](https://github.com/trending)
- [Trendshift](https://trendshift.io/)
- [Star History](https://star-history.com/)

## Steps

1. Read prior `reports/*-breakout.md`; a repo already listed returns only with news (release, growth spike, notable adoption).
2. Pull candidates from every source; favour fit with `INTERESTS.md` at repo root.
3. Separate real adoption from hype: usage evidence, dependents, release cadence.
4. Write `reports/YYYY-MM-DD-breakout.md`: table, columns Project (name + URL), What it is, Why it matters, Verdict (adopt / learn / skip).
