## Team and maturity

- **Beacon:** organization-owned, early project with external contributors; exact core team size unverified. MIT. Recent cross-harness fixes are stronger accessibility evidence than stars. See [repository](https://github.com/Asymptote-Labs/agent-beacon) and merged PRs above.
- **DS Harness Remote:** individual-owned, early plugin/client project with several outside contributors. MIT is declared in the [nested plugin license](https://github.com/liguobao/ds-harness-remote/blob/main/packages/plugin/LICENSE), although GitHub repository metadata reports no root license. Confirm the intended module's coverage before contributing.
- **Cindy:** organization-backed client project, created July 2026; core team size unverified. Apache-2.0. [Contribution guide](https://github.com/makecindy/cindy/blob/main/CONTRIBUTING.en.md) covers desktop/mobile/shared packages; server is separate. Detailed engineering rules and DCO; much discussion is Chinese. Issue #7337 was open and unassigned when checked; its diagnosis remains a reporter claim to reproduce.
- **Ardia:** explicitly [one-person maintained](https://github.com/mantrakp04/ardia/blob/main/CONTRIBUTING.md), shipping frequent nightlies and welcoming PRs. [Build requirements](https://github.com/mantrakp04/ardia#build-it-yourself): Apple Silicon, macOS, Xcode, CocoaPods, Node and pnpm. Distribution GPL-3.0; own source Apache-2.0. Prefer shell/UI work using the prebuilt engine. Issue #460 was open and unassigned when checked.
- **Open Ontologies:** individual-owned, early Rust project; outside contributors demonstrably merged. Exact core team size unverified. MIT. Try the tool before investing in ontology-domain work. See [repository](https://github.com/fabio-rovai/open-ontologies) and PRs above.

## Discovery and limits

Star History's weekly leaders did not improve this shortlist after size/fit filtering.

Seven-day percentages come from [Ageshio's Oct 26 snapshot](https://ageshio.dev/); approximate current totals from each repository's GitHub API. These are different observation times; do not calculate growth between them or interpret Trendshift's displayed numbers as total stars. All five had GitHub pushes on Oct 26. Stars establish attention, not sustained usage or hiring prospects. Real bug reports and external merges add evidence, but durable adoption and future review responsiveness remain unverified. Recheck open issues and competing PRs before claiming work.

Deprioritized Hallmark (~36k stars) and Impeccable (~89k): less early than the README target. Declscope (~50 stars) is interesting, but had no open unassigned issues in the search, so offers a less concrete first contribution.
